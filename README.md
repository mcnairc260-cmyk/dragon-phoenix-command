# Dragon Phoenix Command

The Cognitive Command Center — the web platform of the **Dragon Phoenix Ascension (DPA)** ecosystem.

> *Fire Within. Power Unleashed.*

## What is Dragon Phoenix Ascension?

A cognitive intelligence platform that helps people understand how they think — attention, motivation, habits, learning, decisions — and build systems that turn understanding into action. Educational, not motivational. Systems, not willpower. AI as amplifier, never replacement.

Founding documents: the **DPA Constitution v1.0** and **Master Blueprint v1.0** (source of truth for everything below).
