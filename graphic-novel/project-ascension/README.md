# Project Ascension — graphic novel

Mature-rated, 26-page graphic novel. Chapter 1 art/concept: Courtney McNair (ChatGPT). Chapters 2–3 script, art direction and page art generated with Claude + Higgsfield (Nano Banana 2).

- `index.html` + `img/` — the page-by-page reader (self-contained; open in a browser).
- `script.py` — the full script: every caption, balloon, and image prompt.
- `build_reader.py` — rebuilds `index.html` from the script and images.
- `art-src/` — full-resolution generated page art (PNG, no text baked in).
- `chapter1_source.png` — the original Chapter 1 sheet.
