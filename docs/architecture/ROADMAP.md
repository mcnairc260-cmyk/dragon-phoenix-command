# ROADMAP — FROM PERSONAL OS TO AI-POWERED BUSINESS PLATFORM

Versioned evolution of the whole ecosystem. Versions are **capability states, not dates** — a version ships when its exit criteria are true, and the Constitution's Art. XIV framework gates every addition. The Notion home-page "Future Ideas" parking lot feeds this roadmap; this roadmap sequences it.

**Where we are today: v1.0** — doctrine layer complete; Notion OS built (Phase-1 slice active); site = personal mentor MVP; channel unlaunched; 2 media assets; zero automations live.

## v1.1 — "Coherent" (weeks)
One system instead of two; first outputs shipping.
- Split-brain fixes: doctrine↔operations cross-links, 30-video import, palette/typography reconciliation, single Phase-1 priority sentence (Audit C1/C2/H1)
- Web app repair bundle: model ID, CORS, rate limit, server-side prompt (C4/H2)
- Assets archived + backups running (C3/H5, A14 manual)
- First Etsy listing live **and** YouTube channel shell up (About, banner, trailer-teaser from existing assets)
- Schema hygiene while DBs are empty (H3/H4/M1/M2)
**Exit:** a stranger AI given only CLAUDE.md reconstructs the whole system; first dollar or first video, ideally both.

## v1.2 — "Producing" (months)
The content engine runs as a loop, not a heroic act.
- Videos 1–3 published via SOP 10; Shorts cut from each; Wave-1 automations live (A1–A5)
- Newsletter #1 (Beehiiv) + A9 draft pipeline; site gains email capture (first public-platform step)
- Full 90s trailer rendered when credits allow (plan in PRODUCTION_ASSETS)
- First Flight Data post-mortem published (video 12 pattern)
**Exit:** 4-week publish streak sustained with ≤ 1 founder-day/video; metrics arrive without typing.

## v2.0 — "Compounding" (quarters)
Knowledge and audience start feeding each other; the platform earns its name.
- Command Center website v2: public Cognitive Command Center (first tools: Fortress Hour timer, Evidence Ledger, decision framework) with the personal mentor moved behind auth — resolves the site's identity split
- Knowledge Base > 500 entries with A13 linking; analytics warehouse (A18) as source of truth, Notion as UI
- Content pipeline automations complete (A6–A8); 25+ videos; channel monetized or sponsor-ready
- First digital product beyond Etsy (template pack / mini-course) reusing video systems
**Exit:** something sells while the founder sleeps; a viewer can *use* a DPA tool, not just watch.

## v3.0 — "Platform" (year+)
Multiple revenue lines, first collaborators, agents with real jobs.
- Learning system (A22) becomes a user-facing product: courses/cohorts on the Command Center
- Agent fleet: 3–5 registered agents (research, repurposing, analytics, ops) with run-logs (A19) and computed performance scores; founder reviews, agents execute
- First human collaborator (editor or ops) onboarded **using only the docs** — the onboarding manual's real test
- Permissions model activated (SYSTEM_OVERVIEW §4); multi-business Finance separation (CLIPFORGE / DPA media / products)
**Exit:** a week of founder vacation where revenue, publishing, and ops continue.

## v5.0 — "Company" (years)
- DPA = small media-and-software company: team of humans + agents, multiple products, community (the Aviary) live with Constitution Art. XII as its code of conduct
- The Command Center is the product: users run their own Ascension Loops with the same tools the company runs on (the OS itself, productized)
- Educational media library deep enough that the Archive is a moat; brand licensing/partnerships possible
**Exit:** the Blueprint's "scalable media company, educational platform, and software ecosystem" sentence is literally true.

## v10.0 — "Ecosystem" (the Art. XIII horizon)
The Constitution's roadmap fulfilled: Global Knowledge Ecosystem — the cognitive OS as infrastructure others build on (APIs, integrations, practitioner community), resilient to model/platform churn because doctrine, data, and distribution are all owned. Details deliberately unplanned: **v10 exists to point the compass, not to schedule work** — build for decades, not days, but plan in quarters.

**Standing rule:** anything proposed out of sequence goes through the gauntlet with one extra question — *does it pull the current version's exit criteria closer?* If not, it parks.
